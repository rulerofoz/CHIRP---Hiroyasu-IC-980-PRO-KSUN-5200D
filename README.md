I edited the encoder because it wasn't transferring the tones correctly for me.

I also made it so it works correctly when Duplex is set to "off"


Instructions:
Download this entire repo.
Install Python.  You probably need to check that PATH option. (Maybe?)
Create a new CSV file with CHIRP.  Your channel names probably just have to be 10 characters or less.
Place your CSV file next to the "ChirpCSV_to_YSF.py" file.
Drag your CSV file onto the the "ChirpCSV_to_YSF.py" file.
You now have a YSF file you can open with the CPS for these radios.


If you need the CPS, you can usually grab it at the ABBREE website.

It's also on the Archive for safe keeping.  https://archive.org/details/sf-8118
